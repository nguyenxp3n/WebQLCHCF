# Penpot UI/UX Design Guide - WebQLCHCF Adapter

Use this skill to create professional, user-centered designs before coding.

Core principles:
- Clarity over cleverness.
- Consistency builds trust.
- User goals first.
- Accessibility is not optional.
- Design with real content and real business flows.

Default tokens:
- 8px spacing system.
- 16px minimum body text.
- Clear H1/H2/H3 hierarchy.
- Primary color for main CTAs.
- Success/warning/danger for system states.
- Neutral background for admin workspace.

Accessibility checks:
- Text contrast.
- Touch target 44px minimum.
- Visible focus state.
- Input labels above inputs.
- Do not rely on color alone.
- Proper heading hierarchy.

Dashboard pattern:
- Sidebar 240px desktop.
- Header/topbar 64px.
- Page title + actions.
- Statistic cards.
- Data tables.
- Recent activity.
- Warning panels.

Form pattern:
- Labels above inputs.
- Validation near field.
- Required indicators.
- Logical tab order.
- Clear primary/secondary actions.

Navigation pattern:
- Current page clearly active.
- Group menu by business area.
- Mobile offcanvas.
