# Refactor Skill

Goal:
Improve maintainability without changing behavior.

Use for:
- Extracting repeated markup.
- Renaming unclear variables.
- Splitting large files.
- Removing duplication.
- Introducing helper methods only when safe.
- Keeping external behavior unchanged.

Rules:
- Preserve behavior.
- Make small changes.
- Keep tests/build passing.
- Avoid broad architecture changes.
- Prefer readability.
