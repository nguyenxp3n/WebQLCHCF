# Premium Frontend UI Craftsmanship - WebQLCHCF Safe Adapter

This skill normally targets immersive high-end frontend experiences. For WebQLCHCF, restrict it to premium admin dashboard polish.

Allowed:
- Better card layout.
- Better tables.
- Better forms.
- Better buttons.
- Better sidebar/topbar.
- Better typography.
- Better spacing.
- Light hover/focus transitions.
- Bootstrap Icons.
- Subtle shadows and rounded corners.

Forbidden:
- Heavy animation.
- Scroll-driven storytelling.
- Custom cursor.
- GSAP.
- Lenis.
- 3D/WebGL.
- Landing page hero sections.
- Full-screen cinematic transitions.

Performance rules:
- Animate only transform and opacity.
- Avoid animating width, height, top, margin.
- Use transitions around 0.15s-0.2s.
- Respect prefers-reduced-motion.
