# Web App Testing

Use this skill to validate a web application after UI or behavior changes.

Test:
- Page loads.
- Console errors.
- Navigation.
- Forms.
- Modals.
- Dropdowns.
- Authentication.
- CRUD flows.
- Responsive screenshots.
- Visual regressions.
- Important business flows.
