# Project Rules

## Mục tiêu duy nhất

Build web C# ASP.NET Core MVC dựa trên database `QLCHCF` đã có.

## Không mở rộng quá mức

Không thêm các thành phần sau nếu chưa được yêu cầu:

- Docker
- CI/CD
- CodeQL
- Dependabot
- Unit test nâng cao
- Web API riêng
- React/Angular/Vue
- Blazor
- ASP.NET Identity
- Multi-layer architecture quá phức tạp
- Repository/Unit of Work nếu bài không yêu cầu

## Tên project

Tên project Visual Studio: `WebQLCHCF`.

Namespace mặc định: `WebQLCHCF`.

Nếu namespace thực tế khác, phải sửa đồng bộ toàn bộ file.
