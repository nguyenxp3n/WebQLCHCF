# Web Design Reviewer

Use this skill after UI changes.

Review:
- Responsive layout.
- Visual hierarchy.
- Spacing consistency.
- Typography consistency.
- Color contrast.
- Focus states.
- Accessibility labels.
- Table overflow.
- Modal behavior.
- Navigation behavior.
- Empty/loading/error states.

Fix issues directly in source code when possible.
